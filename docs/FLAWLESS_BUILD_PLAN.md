### 1.1 Frozen EXE Loader Fix (G12)
Status: .pyd embedded (verified), loader code added (verified), but frozen .exe still exits 127.
Root cause: Windows CreateProcess resolves python311.dll relative to .exe, but .pyd requires _internal directory in PYTHONPATH at import time (before Python code runs).
Fix:
  a. In build.spec (generated by scripts/build_pyinstaller.py): add (.pyd file, '.') as binary, not data — ensures loader sees it.
  b. In scripts/build_pyinstaller.py line 296: add pyd_src to binaries array (DONE — verified).
  c. In gui/__main__.py: add sys.path.insert before any import (DONE — verified line 181).
  d. Verify with: run rebuilt EXE, check debug.log for "LOADED v2".
